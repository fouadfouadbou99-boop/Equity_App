# Portfolio Analytics Dashboard

Application Streamlit permettant :

- Suivi de la VL du portefeuille
- Comparaison avec le MASI RB
- Analyse de performance
- Analyse de risque
- Alpha
- Beta
- Tracking Error
- Information Ratio
- Hit Ratio
- Sharpe Ratio
- Export Excel
- Export PDF
- Connexion Power BI

## Installation

```bash
git clone https://github.com/votre_repo/portfolio-analytics.git

cd portfolio-analytics

pip install -r requirements.txt
